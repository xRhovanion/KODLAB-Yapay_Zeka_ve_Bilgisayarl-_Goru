## 💻 Projeler ve Çalışma Alanları

KODLAB kapsamında yapay zekâ ve bilgisayarlı görü alanlarıyla ilişkili farklı algoritmalar ve uygulamalar incelenmektedir.

### 1. Benzerlik Algoritmaları

Metinler, vektörler ve sayısal veriler arasındaki benzerlik ilişkilerini değerlendirmek amacıyla kullanılan yöntemler.

Örnek çalışmalar:

- Cosine Similarity
- Levenshtein Similarity
- Matrix Similarity
- Vector Space Similarity

### 2. Bulanık Mantık

Kesin sınırlarla ifade edilemeyen durumların matematiksel olarak modellenmesinde kullanılan bulanık mantık yaklaşımları.

Örnek çalışmalar:

- Fuzzy Logic Control Unit
- Bulanık üyelik fonksiyonları
- Bulanık mantık tabanlı kontrol uygulamaları

### 3. Makine Öğrenmesi

Verilerden örüntülerin öğrenilmesi, sınıflandırma, regresyon ve tahmin problemlerinin incelenmesi.

Örnek çalışmalar:

- Decision Trees
- Random Forest
- K-Nearest Neighbors (KNN)
- K-Means Clustering
- Linear Regression
- Logistic Regression
- Polynomial Regression
- Support Vector Machines (SVM)

### 4. Görüntü İşleme ve Bilgisayarlı Görü

Dijital görüntülerin işlenmesi, analiz edilmesi ve görüntülerden anlamlı bilgilerin elde edilmesine yönelik çalışmalar.

Bu alandaki uygulamalar, ilgili konuların öğrenilmesine ve projelerin ilerleyişine bağlı olarak geliştirilmektedir.

### 5. Grafik Kullanıcı Arayüzleri (GUI)

Python uygulamalarının daha erişilebilir ve yönetilebilir olması amacıyla grafik kullanıcı arayüzleri geliştirilmesi.

## ⚙️ Kurulum ve Kullanım

Projeler Python programlama dili temel alınarak hazırlanmıştır.

Gerekli kütüphaneler, ilgili proje klasörlerinde bulunan bağımlılık dosyaları üzerinden kurulabilir.

### 1. Depoyu bilgisayara indirme

```bash
git clone https://github.com/xRhovanion/KODLAB-Yapay_Zeka_ve_Bilgisayarl-_Goru.git
```

Alternatif olarak GitHub üzerinden **Code → Download ZIP** seçeneği kullanılabilir.

### 2. Sanal Python ortamı oluşturma

```bash
python -m venv .venv
```

Windows üzerinde etkinleştirme:

```cmd
.venv\Scripts\activate.bat
```

### 3. Gerekli kütüphaneleri yükleme

```bash
python -m pip install -r requirements.txt
```

Grafik arayüzün ek bağımlılıkları için:

```bash
python -m pip install -r GUI/requirements-gui.txt
```

### 4. Uygulamaları çalıştırma

KODLAB arayüzü için ilgili Python dosyası çalıştırılabilir:

```bash
python GUI/GUI.py
```

**Not:** Bazı uygulamalar kendi klasörlerindeki veri dosyalarına veya ek kütüphanelere ihtiyaç duyabilir. Projelerin çalışma koşulları birbirinden farklılık gösterebilir.
